# Templates

This folder contains practical formats that can be used directly in real work.

The goal of this folder is to provide ready-to-use tools that help plan, review, and improve product UI more effectively.

## Rules

Before adding a new file, answer these questions:

1. Can this be used directly in real work?
2. Does it help with planning, reviewing, checking, or refining product UI?
3. Is it structured as a working format rather than an explanation?
4. Would this save time, reduce uncertainty, or improve consistency in practice?
5. Is it specific enough to be actionable?

## What does not belong here

This folder is not for:

- articles
- general explanations of a topic
- broad theory
- high-level principles
- collections of links

## Reminder

Templates are meant to be used, not just read.
