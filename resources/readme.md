# Resources

This folder contains selected references that help support better product UI decisions.

The goal is not to collect everything.

The goal is to keep only the resources that are genuinely useful in real work and directly support the purpose of this repository.

## Rules

Before adding a new reference, answer these questions:

1. Does it help build better product UI?
2. Would I return to this resource during real work?
3. Does it add something specific and meaningful instead of something generic or obvious?

## Examples of what not to add

- broad resource dumps
- interview prep
- career materials
- trend-based collections
- loosely related tools

## Reminder

Resources should support the repository and not become the repository.
