# Resource Sparks

Candidate references that may be useful for Product UI work but have not yet earned a place in `references.md`.

A resource can graduate when it has proved useful in a real Product UI case, implementation decision, review, repeated observation, or deliberate validation.

---

- [Designing Empty States in Complex Applications](https://www.nngroup.com/articles/empty-state-interface-design/) — candidate reference for empty-state decisions and providing a useful path forward.

- [Empty State UX Examples & Best Practices](https://www.pencilandpaper.io/articles/empty-states) — candidate reference for enterprise and data-heavy empty states.

- [4 Principles to Reduce Cognitive Load in Forms](https://www.nngroup.com/articles/4-principles-reduce-cognitive-load/) — candidate framework for reasoning about complex forms.

- [Dangerous UX: Consequential Options Close to Benign Options](https://www.nngroup.com/articles/proximity-consequential-options/) — candidate reference for placement of destructive or consequential actions.

- [How To Manage Dangerous Actions In User Interfaces](https://www.smashingmagazine.com/2024/09/how-manage-dangerous-actions-user-interfaces/) — candidate reference for confirmation patterns and varying levels of destructive-action severity.

- [Delete with additional confirmation](https://cloudscape.design/patterns/resource-management/delete/delete-with-additional-confirmation/) — candidate production pattern for high-consequence deletion flows.

- [Hidden vs. Disabled in UX](https://smart-interface-design-patterns.com/articles/hidden-vs-disabled/) — candidate reference for permission- and availability-dependent actions.

- [Data Table Design UX Patterns & Best Practices](https://www.pencilandpaper.io/articles/ux-pattern-analysis-enterprise-data-tables) — candidate reference for dense enterprise data tables.

- [Enterprise Filter UX Design Patterns](https://www.pencilandpaper.io/articles/ux-pattern-analysis-enterprise-filtering) — candidate reference for filtering in complex data-heavy products.

- [What Is an Ecommerce Filter? UI Best Practices](https://baymard.com/learn/ecommerce-filter-ui) — candidate evidence-based reference for filtering; ecommerce-specific, so validate applicability outside ecommerce.

- [UX Patterns for Developers](https://uxpatterns.dev/) — candidate implementation-facing pattern reference; broad resource, so validate specific recurring use before graduation.

- [WAI-ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) — candidate interaction and accessibility reference; likely useful across patterns, but should earn graduation through actual implementation use.

- [Recover from validation errors](https://design-system.service.gov.uk/patterns/validation/) — candidate reference for validation failure and recovery flows.

- [Carbon Data Table](https://carbondesignsystem.com/components/data-table/usage/) — candidate production reference for complex table behavior and states.
