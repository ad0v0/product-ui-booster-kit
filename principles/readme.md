# Principles

This folder contains foundational ideas that help shape the right mindset for building strong product UI.

The goal of this space is not to describe every possible UI situation, but to define the core principles behind interfaces that feel clear, reliable, and thoughtful in real use.

## Rules

Before adding a new file, answer these questions:

1. Does it explain a core idea behind strong product UI?
2. Does it help build better judgment, not just give surface-level advice?
3. Is it broad enough to guide many UI situations, not just one specific case?
4. Does it focus on *why* something matters, not only *what* to do?
5. Would this still be useful even without a specific framework, component, or tool?

## Examples of what not to add

This folder is not for:

- lists of edge cases
- checklists
- concrete component patterns
- links without explanation

## Reminder

Principles explain *why* strong product UI works the way it does.

They should help build better judgment, not just provide rules to follow.
